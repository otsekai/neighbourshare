# NeighbourShare

NeighbourShare — это фулстек P2P (peer-to-peer) платформа, разработанная для совместного использования вещей внутри локальных сообществ. Сервис позволяет снизить уровень избыточного потребления и развивать взаимопомощь между соседями. Пользователи могут публиковать свои вещи, просматривать локальный каталог в реальном времени, управлять активными арендами, а также администрировать доступ участников через специализированную панель управления.

## Основные возможности

- **Динамический локальный каталог:** Адаптивная витрина для просмотра доступных товаров с обновлением данных в реальном времени.
- **Система управления бронированием:** Асинхронная отправка заявок с возможностью фиксации точного времени возврата вещи.
- **Ролевая модель доступа (RBAC):** Разделение интерфейса и доступных действий для обычных пользователей и администраторов платформы.
- **Панель администратора:** Централизованный пульт управления для контроля участников сообщества, модерации профилей и изменения их статусов.
- **Современный интерфейс:** SPA-подобный фронтенд с поддержкой бесшовного переключения светлой и тёмной тем оформления, асинхронными всплывающими уведомлениями (Toasts) и полной адаптивностью под мобильные устройства.

## Технологический стек

- **Бэкенд:** Java, Spring Boot (REST API, архитектура MVC)
- **База данных:** PostgreSQL (хранение данных пользователей, инвентаря и сессий бронирования)
- **Фронтенд:** HTML5, CSS3 (кастомные переменные, адаптивная сетка), ванильный JavaScript (Fetch API, модульная структура скриптов)
- **Стилизация:** Bootstrap 5, Bootstrap Icons

## Запуск проекта

### Требования
- Java 17 или выше
- Установленная и запущенная СУБД PostgreSQL
- Система сборки Maven

### Локальный запуск
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd neighbourshare
   ```
2. Настройте подключение к вашей базе данных PostgreSQL в файле `src/main/resources/application.properties` (укажите ваш url, username и password).
3. Запустите Spring Boot приложение через вашу IDE или терминал:
   ```bash
   # Для проектов через Maven:
   ./mvnw spring-boot:run
   
   # Для проектов через Docker:
   docker compose up --build
   ```
4. Откройте браузер и перейдите по адресу `http://localhost:8080`
